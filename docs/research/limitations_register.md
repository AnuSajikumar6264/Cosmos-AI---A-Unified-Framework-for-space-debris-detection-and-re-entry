## Dependencies and unresolved decisions

- A real linked evaluation of health-to-conjunction or health-to-re-entry requires a new,
  lawful and technically linkable source; this cannot be solved by code changes alone.
- Acquiring restricted orbital data or redistributing downloaded archives requires explicit
  user authorization and license review. No such acquisition or redistribution is part of
  this audit.
- Confirmatory design for future temporal tests should be fixed before test outcomes are
  inspected.
- The next software step should improve contracts and lineage without changing scientific
  targets, split definitions, priors, or existing result artifacts.
