### A.6 Findings from Phase 0 that shape the later phases

1. **Two contribution framings coexist, unreconciled.** `NOVELTY_AND_CONTRIBUTION_STATEMENT.md`
   (rev 2, 2026-11-04) retains **C-1…C-5**, all centred on orbital lifetime (catalogue-scale
   censoring-aware benchmark; selection non-transfer; reproducibility-failure analysis; narrow
   measurements; preserved negatives) and withdraws six including *satellite digital twin* and
   *integrated cross-domain framework*. The JINT manuscript (2026-11-05) rests on the **ESA-ADB
   alarm-layer selection** result, which is absent from that statement. → Phase 1.
2. **OPS-SAT per-seed scores were produced and then lost.** `cosmos/ai/telemetry/opssat.py:345`
   writes `test_scores_<tag>.npz`; `.gitignore:32` excludes `*.npz` with exceptions for four
   other directories but **not** `telemetry_opssat`. `report.py:247` loads it unconditionally and
   would now fail. Re-running OPS-SAT is cheap (18.6 MB corpus; experiment timestamps ≈10 s
   apart) and is itself a reproducibility test. → Phase 2.1 / 6.
3. **The validated chain depends on legacy physics** for the footprint surrogate (A.2). → Phase 2.4.
4. **Conjunction "screening" is not what the directive describes.** `cosmos/ai/conjunction` predicts
   final-CDM risk from Kelvins CDM histories; it does not ingest state vectors, propagate, or
   compute closest approach. The directive's §5.5 items on propagation/TCA have no data path.
   → Phase 2.5, likely NOT EVALUABLE with available data.
5. **`tests/test_product.py` writes real run directories** into `outputs/pipeline/` — two per
   invocation (71 → 73 measured; `test_orchestration`, `test_integration`, `test_dashboard`,
   `test_end_to_end` all use `tmp_path` and write none). The console API resolves
   `store.PIPELINE_RUNS = "outputs/pipeline"` against `ROOT`. Hygiene issue for reproducibility
   and for the 71-run count in A.4. → Phase 6/7: redirect the product tests to `tmp_path`.
6. **Weak environment pinning** (2 of 32 packages). → Phase 6.
7. **Manuscript claim audit** (`scripts/audit_manuscript_claims.py`, 146 checks): 129 PASS,
   9 FAIL, 8 NOT_EVALUABLE. **Parked** — the directive locks writing until Phase 8. Recorded in
   Phase 9 below so nothing is lost.
8. **Three checks skip silently inside tests pytest reports as passed** (found 2026-11-06 by
   running `tests/test_ai.py -s`): `test_pipeline_backward_compatible` → "baseline snapshot
   missing" (`outputs/baseline/cosmos_baseline_src_2026-10-24.tar.gz` is absent, so the legacy
   simulator's fault→health→hazard reproduction against the original code is **not verified**);
   `test_learned_backends` → "learned telemetry backend" and "surrogate footprint" checkpoints
   absent. `test_ai.py::skip()` appends a SKIP record and prints, but does not tell pytest. The
   suite total therefore overstates verification by two tests. → Phase 2.2 / 6: make skips
   visible as pytest SKIPPED without losing the checks that do run; recover the baseline from git
   history if it is an earlier commit's tree.
9. **The `decision_priority` health gate has no adapter-level test.** Console
   (`test_product.py::test_11_c4_escalation_abstains_with_a_reason`) and coupling
   (`test_couplings_regression.py::test_c3_escalation_rule_never_raises_physical_risk`) levels are
   covered; the three abstention branches in `adapters.decision_priority` (health present but not
   linked; linked asserted by config; health not requested) are not. → Phase 2.2.
