# Dataset provenance and availability

Snapshot basis: repository data manifests and [`docs/DATASET_AUDIT.md`](../DATASET_AUDIT.md),
primarily retrievals dated 2026-10-27. This document distinguishes raw observations,
derived tables, simulated data and unavailable data. Licenses/terms must be checked at
redistribution time; a public URL is not itself a redistribution license.

## Datasets used in reported studies

| Dataset | Class / source | Use | Provenance and constraints |
|---|---|---|---|
| GCAT release 1.8.8 snapshot | Real catalogue; CC-BY-4.0 as recorded in project audit | Canonical orbit, decay dates, status, design properties, launch/breakup family | Snapshot under `data/feature2_debris/gcat/raw/2026-10-27/`; dated because catalogue content changes. Raw and derived files have manifests. |
| CelesTrak SATCAT, GP and SW-All snapshots | Real catalogue/orbital/environment data; CelesTrak usage policy, no explicit license recorded | Current orbit, status, space-weather covariates; observed rows only for feature construction | Snapshots under `data/feature2_debris/celestrak/`. Avoid redistributing beyond applicable terms. RCS is excluded as a predictor because availability is outcome-associated; it is retained only for the documented training-derived class size prior. |
| ESA Kelvins Collision Avoidance Challenge | Real benchmark CDMs; CC-BY-4.0 per audit | Final-CDM collision-risk prediction | Anonymised; cannot be linked to catalogue identities. Training is filtered to match official test protocol; high-risk cases are rare. |
| ESA-ADB | Real telemetry; source/license details in per-dataset manifest | Health/anomaly benchmark | Missions anonymised; cannot be joined to tracked catalogue objects. Dataset version and archive checksums are recorded. |
| ESA OPSSAT-AD | Real telemetry benchmark; source/license details in manifest | Health/anomaly benchmark | No link to the re-entry population. Benchmark splits must be respected. |
| NASA SMAP/MSL telemetry (Kaggle copy of telemanom data) | Real telemetry; Caltech/BSD-style terms and Kaggle attribution caveat recorded in audit | Supplementary detector comparison | Original S3 archive returned HTTP 403 at retrieval; used copy's labels were byte-identical to repository labels. Values use test-set min/max scaling as described by original authors. |
| SpotGEO v2 | Real benchmark imagery; manifest is authoritative for terms | Debris/image detection benchmark | Used for benchmark evaluation; limited seed/condition breadth and no independent observing dataset. |
| ESA recovered debris / DISCOS public list | Real records, no explicit license recorded | Record linkage and context checks | Not re-entry state vectors or impact-point ground truth; not suitable as independent trajectory validation. |
| NRLMSIS 2.1 density table | Derived/model output using pymsis 0.13.0 | Re-entry physics model | Globally averaged across season, local time and latitude; model output, not measured atmosphere. |
| Lifetime cohort | Derived from GCAT/CelesTrak | Lifetime/re-entry prediction | 64,516 objects and 32,970 natural decays per the dataset audit; inherits upstream terms and filtering decisions. |

## Downloaded but not used for main claims

| Dataset | Reason |
|---|---|

## Integrity and custody

- Dataset manifests record file paths, sizes, hashes and source metadata. A combined manifest
  is generated by `scripts/build_dataset_manifest.py`.
- Downloader behavior is documented to preserve immutable raw files, verify checksums,
  record retrieval metadata and distinguish unavailable sources.
- Dataset status checks verify manifest-listed file presence and sizes; they do not
  recompute all hashes on every query. Run explicit integrity validation for critical
  reproductions.
- A user-supplied `ftocat.tsv` was verified byte-identical to the existing GCAT snapshot
  (`SHA-256 6826ab6ab916cea7de0c328dae9ee761b6c304350b4447f8988e0f18a42a3ac5`,
  511,727 bytes); it was not copied or modified.
- ESA-ADB archives downloaded under prior user authorization were validated locally only.
  Their checksums and conversion results are recorded in the existing run report; no
  redistribution is implied or performed.
