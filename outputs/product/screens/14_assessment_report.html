9. Limitations

  • No dataset in this repository links telemetry health, conjunction messages and catalogue outcomes for the same spacecraft, so no end-to-end health-to-re-entry chain is empirically validated (limitation L1).
  • Re-entry intervals are physics Monte-Carlo quantiles over area-to-mass and space-weather draws. They are not conformal intervals and carry no distribution-free coverage guarantee (limitation L8).
  • The existing as-of 2026-08-16 temporal evaluation (T1) is not blind and is exploratory evidence, not confirmatory (limitations L2, L3).
  • Prospective evaluation of the dated 2026-10-27 forecast is blocked: no qualifying later outcome snapshot exists (limitation L3b).
  • The saved per-horizon calibrated lifetime probabilities are calibrated independently per horizon and are not guaranteed to form a coherent CDF (limitation L17). The twin's final reported forecast is unaffected.
  • No validated impact coordinate, ground track, footprint or recovered-fragment location is available for any object (limitation L5).
  • Software tests passing is not scientific validation.
  • subgroup under-coverage (descriptive, X6 Stage 1): this object's area-to-mass value is design-derived; at the archived evaluation origin 2016 the 80 % intervals of this construction covered 0.5625 (95 % CI 0.512-0.614) of design-derived objects against a nominal 0.80. This is an observed subgroup frequency, not this object's coverage probability, not a causal explanation, and not a statement about the deployed snapshot, which has no outcomes
